# KnockKnockBro

**Meetings. No surprises.**

[![Последний релиз](https://img.shields.io/github/v/release/le0hard/KnockKnockBro)](https://github.com/le0hard/KnockKnockBro/releases/latest)

KnockKnockBro — небольшой нативный помощник для онлайн-встреч в строке меню macOS. Хранит ссылки на встречи в одном месте, показывает, что впереди, «стучится», когда пора, — и, если разрешить, сам подключается после видимого обратного отсчёта.

Приложение не привязано к одному сервису. Основной сценарий — Яндекс Телемост (в том числе его приложение для Mac), но работают и Google Meet, Zoom, Microsoft Teams, и любая другая ссылка на встречу.

## Скачать

Скачайте последний `KnockKnockBro-vX.Y.Z.zip` со страницы [**Releases**](https://github.com/le0hard/KnockKnockBro/releases/latest), распакуйте и перенесите **KnockKnockBro.app** в «Программы».

> Приложение не нотаризовано через Apple Developer ID, поэтому при первом запуске macOS его заблокирует. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть** — это нужно один раз для каждой версии.

О новых версиях KnockKnockBro сообщит сам (см. [Обновления](#обновления)).

## Возможности

### Строка меню — на первом месте
- Отсчёт до следующей сегодняшней встречи прямо в строке меню (`12m`), а если сегодня встреч больше нет — просто иконка.
- Попап со следующей встречей, расписанием на сегодня и постоянными комнатами: крупное выровненное время `ЧЧ:ММ` и под ним «через 12 мин», плавно мигающее двоеточие, компактные кнопки подключения и копирования, **Пропустить** у следующей встречи, подсветка строк как в системных меню.
- Один клик до Календаря, главного окна или Настроек.

### Встречи
- **Быстрый доступ** — постоянные ссылки для незапланированных созвонов.
- **Повторяющиеся встречи** — каждый день, по будням, еженедельно или в любые выбранные дни.
- **Разовые встречи** — в конкретный день, по желанию удаляются сами через час после начала; прошедшие попадают в **Архив**.
- **Автоматическое определение сервиса** по ссылке: Яндекс Телемост, Google Meet, Zoom, Microsoft Teams — любая другая ссылка сохраняется и открывается как есть.
- **Приложение Яндекс Телемоста** — подключение в приложении, в браузере или выбор каждый раз.
- **Включить / выключить** встречу, не удаляя её; **Пропустить сегодня** отменяет один день, не трогая расписание.

### Напоминания и подключение
- Сколько угодно напоминаний на встречу, у каждого своё время и звук.
- **Подключиться** и **Через 5 минут** прямо из уведомления.
- **Автоподключение** — плавающая панель с обратным отсчётом (5–60 с или своё значение) перед открытием ссылки: **Подключиться сейчас**, **Я уже на встрече** или **Отмена** только на сегодня. KnockKnockBro никогда не открывает встречу без предупреждения.
- **Помнит, что вы уже подключились** — нажатие «Подключиться» начиная с 15 минут до начала (настраивается) и до конца дня отмечает встречу: в этот день больше нет автоподключения, напоминаний и вопросов, а у встречи зелёная галочка.
- **Учитывает сон Mac** — если Mac спал в момент начала встречи, вместо сюрприза будет «Daily начался 3 минуты назад — Подключиться / Пропустить».
- Прошедшие встречи зачёркнуты — ход дня виден сразу.

### Календарь и главное окно
- **Календарь** — месяц с отмеченными днями встреч и список встреч выбранного дня.
- **Главное окно** — «Сегодня» / «Все встречи» / «Быстрый доступ» / «Архив», с кнопкой «Копировать» (название, время и ссылка) и стандартным меню **Поделиться** macOS.

### Ваши данные
- **Экспорт и импорт** в одном человекочитаемом JSON-файле с версией формата — встречи *и* настройки приложения. Можно выбрать, какие встречи (и нужно ли настройки) экспортировать или импортировать, **объединить** или **заменить**, перетащить файл на окно. Каждый файл сначала полностью проверяется; некорректный файл никогда не меняет ваши данные.
- **Полностью локально** — без аккаунта, без сервера, без телеметрии.

### Обновления
Не чаще раза в день и только при открытии Настроек (никогда при запуске) KnockKnockBro спрашивает у GitHub Releases, нет ли новой версии, и предлагает открыть страницу загрузки. Проверить вручную — кнопка **Проверить обновления** в Настройках или окне «О KnockKnockBro». Само приложение ничего не скачивает и не устанавливает.

## Приватность

- Встречи хранятся в `~/Library/Containers/…/Application Support/KnockKnockBro/meetings.json`, настройки — в стандартных настройках приложения.
- Единственный сетевой запрос, который KnockKnockBro делает сам, — проверка обновлений на `api.github.com`. Ссылки на встречи открывает macOS — в браузере или приложении сервиса.

- macOS 14 (Sonoma) или новее

## Сборка из исходников

```bash
git clone https://github.com/le0hard/KnockKnockBro.git
cd KnockKnockBro
open KnockKnockBro.xcodeproj
```

Запуск — `⌘R`, тесты — `⌘U`. Сторонних зависимостей нет — обычное SwiftUI-приложение.

## Архитектура

Проект организован по зонам ответственности, а не по экранам:

```
KnockKnockBro/
├── KnockKnockBroApp.swift, AppDelegate.swift   — сцены, жизненный цикл приложения
├── MenuBarContentView.swift, MenuBarLabelView.swift — попап и лейбл строки меню
├── Models/     — Meeting, MeetingSchedule, CalendarDay, MeetingReminder, AutoJoinSettings,
│                 MeetingOccurrenceException, AppSettingsSnapshot, …
├── Services/   — MeetingStore, OccurrenceEngine, NotificationService, AutoJoinService/Runtime,
│                 WakeObserver, JoinTracking, MeetingLauncher, MeetingProviderDetector,
│                 ImportExportService, UpdateChecker, LoginItemService, …
└── Views/      — Meetings, MeetingEditor, Calendar, Import, Settings, About,
                  AutoJoinCountdown, Components
KnockKnockBroTests/ — тесты расписания, импорта/экспорта и учёта подключения
```

Несколько решений, о которых стоит знать при чтении кода:

- **Правило и исключения — разные сущности.** Расписание описывает *правило* («по будням в 10:00» или «один раз 5 октября»). Отметки на конкретный день — пропущена, автоподключение отменено, подключился — хранятся в `MeetingOccurrenceException`, поэтому один день никогда не меняет правило.
- **Экземпляры встреч вычисляются, а не хранятся.** `OccurrenceEngine` разворачивает правила в конкретные даты по запросу; им пользуются строка меню, уведомления, автоподключение и календарь, и он покрыт тестами, включая переходы на летнее время и границы месяцев.
- **Уведомления — одноразовые запросы** на 48 часов вперёд, поэтому один день можно пропустить, не отменяя всю серию.
- **Автоподключение — в отдельной плавающей панели `NSPanel`**, независимой от главного окна.
- **Импорт: сначала проверка, потом применение.** `ImportExportService.validate` — чистая функция; ничего не записывается, пока пользователь не подтвердит, а объединение — простая протестированная логика.
- **Версионированный формат файла** (сейчас 3). Новые версии читают все старые файлы; старые версии отклоняют новые файлы с понятным сообщением, а не угадывают.

Полная история изменений и бэклог — в [CHANGELOG.md](CHANGELOG.md).

## Планы

- Встречи из Календаря macOS (EventKit) — импорт или живое подключение
- Автоматические обновления (Sparkle) и канал обновлений на своём домене
- Отдельное окно для вопроса «встреча началась, пока Mac спал»
- Громкость звука напоминаний
- Открытие встреч Zoom / Teams сразу в их приложениях
