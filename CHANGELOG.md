# KnockKnockBro — Changelog

## v0.3.0

Визуальный редизайн интерфейса — приближение к нативным паттернам macOS (Human Interface Guidelines) — плюс согласование кнопки подключения в системных уведомлениях с настройками режима Телемоста и несколько доработок Menu Bar / редактора встречи.

### Визуальный редизайн
- [x] Sidebar главного окна переведён на нативный стиль (`.listStyle(.sidebar)`) — полупрозрачный фон, скруглённая подсветка выбора, как в Finder/Mail
- [x] Пустые состояния везде заменены на `ContentUnavailableView` — иконка + заголовок + описание по центру вместо голого текста
- [x] Settings переработан в паттерн System Settings — sidebar с категориями (Общие / Автоподключение / Сервисы видеосвязи / Импорт-Экспорт), цветные иконки-квадраты, вместо одной длинной формы
- [x] Плавающие панели (попап Menu Bar, countdown-панель Auto Join) используют системный материал (`.regularMaterial` + настоящая AppKit-vibrancy) вместо сплошной заливки
- [x] Попап Menu Bar расширен (280 → 340pt) — длинные названия и две кнопки Телемоста помещаются без обрезания
- [x] «Следующая встреча» в попапе показывает относительное и абсолютное время вместе («через 12 мин · 10:00»)
- [x] Типографика — названия встреч и заголовки крупнее/жирнее второстепенного текста
- [x] Проверен и подтверждён системный accent color — используется напрямую, без переопределения кастомной палитрой (в соответствии с HIG)
- [x] Пункты меню попапа Menu Bar («Открыть KnockKnockBro», «Настройки», «Выйти») получили иконки (SF Symbols)

### Функциональность
- [x] Кнопка «Подключиться» в системном уведомлении теперь учитывает настройку режима Телемоста — ведёт по той же приоритетной ссылке (Desktop/Web), что и остальной интерфейс, вместо всегда открывать браузер
- [x] Кнопка «Открыть KnockKnockBro» в попапе Menu Bar теперь выводит главное окно на передний план и корректно разворачивает его, если оно было свёрнуто в Dock
- [x] В редакторе встречи рядом с полем ссылки добавлена кнопка вставки из буфера обмена

### Исправлено
- [x] Нажатие «Открыть KnockKnockBro» при уже открытом/свёрнутом главном окне сопровождалось системным звуком ошибки — устранено переходом с синтетического Escape-события на `NSApp.activate` + явное `deminiaturize`

### Архитектурная заметка
- `ConnectOptionButton` — переиспользуемый компонент для кнопки подключения (`if/else` вместо тернарного оператора в `.buttonStyle`, см. заметку в v0.2.1) — теперь используется в главном окне, попапе Menu Bar и countdown-панели одинаково
- `NotificationService` восстанавливает `MeetingService` из URL через `MeetingProviderDetector` при обработке нажатия — `userInfo` уведомления не хранит полный объект `Meeting`, только необходимые поля
- Синтетические `NSEvent`-события для управления системным UI (Menu Bar popup) — ненадёжный подход, вызывающий системные алерт-звуки при несовпадении контекста; предпочтительны официальные API (`NSApp.activate`, `\.dismiss` из SwiftUI Environment), даже если конечный результат (автозакрытие попапа) пока не достигнут полностью — см. Backlog v1

## v0.2.1

Патч-релиз — два исправления, обнаруженные сразу после публикации v0.2.

### Исправлено
- [x] Auto Join теперь учитывает настройку режима подключения Телемоста (Desktop/Web/оба) — и при автоматическом срабатывании таймера, и в самой countdown-панели (там теперь тоже 1 или 2 кнопки, как в остальном интерфейсе)
- [x] Версия в About-экране обновлена (поле Version в настройках таргета не было обновлено при релизе v0.2)

### Архитектурная заметка
- `AutoJoinRuntime` и `AutoJoinCountdownView` теперь используют ту же `MeetingLauncher.connectOptions(...)`, что и ручные кнопки в остальном UI — общая логика вынесена в переиспользуемый `ConnectOptionButton`, чтобы Auto Join никогда не расходился с тем, что пользователь видит и выбирает вручную
- Тернарный оператор внутри `.buttonStyle(...)` с разными конкретными типами (`.borderedProminent` / `.bordered`) заставлял компилятор Swift превышать разумное время проверки типов — решение: `ConnectOptionButton`, отдельный `View` с обычным `if/else`

- `MeetingLauncher.connectOptions(for:telemostMode:appAvailabilityCheck:)` — чистая функция, возвращающая массив из одной или двух кнопок; проверка наличия приложения вынесена параметром для тестируемости

### Архитектурные решения, важные для дальнейшей разработки

- **Правило повторения и точечные исключения — разные сущности.** `MeetingSchedule` описывает правило; Skip Today и отмена Auto Join на конкретный день живут в отдельной `MeetingOccurrenceException`, не пересекаясь с правилом.
- **Экземпляры встреч вычисляются, не хранятся.** `OccurrenceEngine` разворачивает правило в конкретные даты по запросу для любого диапазона — используется и уведомлениями, и Menu Bar, и (в будущем) календарём из Backlog v1.
- **Уведомления — дискретные одноразовые запросы**, не единый repeating-триггер: `UNCalendarNotificationTrigger(repeats: true)` не позволяет отменить одно вхождение без отмены всей серии, а это нужно для Skip Today.
- **Формат хранения = формат экспорта** (`StorageFile` в `MeetingStore.swift`) — не дублируется два раза.
- **Auto Join и Missed Meeting — разные зоны ответственности по времени**: Auto Join работает строго до `startDate`, Wake-промпт — строго после.

### Известные платформенные особенности (обнаружено эмпирически, стоит помнить)

- **`UNNotificationSound(named:)` на macOS ищет файл не в бандле, а в `Library/Sounds` контейнера** — и это защищено App Sandbox (`EPERM`). Кастомный звук поэтому проигрывается вручную через `AVAudioPlayer` в `willPresent`, а не через системный механизм.
- **`TimelineView` как лейбл `MenuBarExtra` вызывает бесконечную перерисовку** (100% CPU, полная неотзывчивость) — заменено на `Timer.publish`/`Task`-цикл.
- **`NSApp.windows.forEach { $0.close() }` в `applicationDidFinishLaunching` мешает AppKit корректно инициализировать `MenuBarExtra`** — закрывать нужно только конкретное окно по `identifier`, и с небольшой отсрочкой.
- **`Timer.scheduledTimer` внутри `@MainActor`-класса всё равно не наследует изоляцию** — использован `Task`-цикл с `Task.sleep` вместо него.
- **Xcode Organizer → Distribute App → Debugging теперь требует Apple Developer Program** даже для локального экспорта без публикации — рабочая замена для бесплатного аккаунта: собрать через `Release`-схему обычным `Cmd+B` и скопировать `.app` из `Products/Release/`.
- **macOS (текущая версия) убрала обход Gatekeeper через правый клик → Открыть** — теперь только через System Settings → Privacy & Security → Open Anyway.
- **Яндекс Телемост регистрирует `telemost://`** — прямой deep link на конкретную встречу найден эмпирически и реализован в v0.2 (см. выше), официальной документации по-прежнему нет.
