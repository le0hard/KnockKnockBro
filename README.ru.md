# KnockKnockBro

**Meetings. No surprises.**

KnockKnockBro — небольшой нативный помощник для macOS, который живёт в строке меню, хранит ссылки на онлайн-встречи, показывает предстоящие созвоны, напоминает о них и, если разрешить, сам подключается вместо вас.

Приложение не привязано к конкретному видеосервису. Основной сценарий — Яндекс Телемост, но поддерживается любой корректный URL встречи, а слой определения сервиса спроектирован так, чтобы его легко расширять.

## Возможности

- **Быстрый доступ** — постоянная ссылка для незапланированных созвонов, всегда под рукой.
- **Запланированные встречи** — повторяющиеся встречи: каждый день, по будням, еженедельно, либо в выбранные дни недели.
- **Автоматическое определение сервиса** — Яндекс Телемост, Google Meet, Zoom, Microsoft Teams, и корректная обработка любого другого сервиса.
- **Несколько независимых напоминаний** на одну встречу, у каждого — свой отступ по времени и свой звук.
- **Подключение и «Через 5 минут» прямо из уведомления** — без необходимости переключаться в приложение.
- **Пропустить сегодня** — отменяет один конкретный экземпляр повторяющейся встречи, не трогая само расписание.
- **Включить/выключить** — временно ставит встречу на паузу; уведомления и автоподключение перестают срабатывать, сама встреча остаётся настроенной.
- **Автоподключение** — видимый, отменяемый обратный отсчёт перед тем, как приложение само откроет ссылку встречи. Никогда не открывает ничего без предупреждения.
- **Учитывает сон/пробуждение Mac** — если Mac спал в момент начала встречи, KnockKnockBro не откроет её автоматически задним числом — сначала спросит.
- **Строка меню — на первом месте** — живой обратный отсчёт до следующей встречи прямо в строке меню, с быстрым попапом сегодняшнего расписания и Быстрого доступа.
- **Главное окно с боковой панелью** — «Сегодня» / «Все встречи» / «Быстрый доступ», всё на одних и тех же данных.
- **Экспорт и импорт в JSON** — единый человекочитаемый файл с версионированием формата, поддержкой Drag & Drop и полной валидацией перед применением.
- **Запуск при входе в систему** — через современный API `SMAppService`, без устаревших способов регистрации login item.
- **Полностью локально** — без аккаунта, без сервера, без телеметрии. Все данные — в JSON-файле в вашей собственной папке `Application Support`.

## Требования

- macOS 14 (Sonoma) или новее
- Xcode 16 или новее (для сборки из исходников)

## Сборка из исходников

```bash
git clone https://github.com/<ваш-логин>/KnockKnockBro.git
cd KnockKnockBro
open KnockKnockBro.xcodeproj
```

Соберите и запустите через `Cmd+R`. Никаких сторонних зависимостей и настройки пакетного менеджера не требуется — обычное SwiftUI-приложение.

> KnockKnockBro не нотаризован через Apple Developer ID. Если вы скачали готовую `.app`-сборку, а не собрали её сами, macOS Gatekeeper первоначально её заблокирует — откройте **System Settings → Privacy & Security → Security** и нажмите **Open Anyway**.

## Архитектура

Проект организован по зоне ответственности, а не по экранам:

```
KnockKnockBro/
├── Models/       — Meeting, MeetingSchedule, MeetingReminder, AutoJoinSettings, исключения
├── Services/     — MeetingStore, OccurrenceEngine, NotificationService, AutoJoinService,
│                   MeetingLauncher, MeetingProviderDetector, ImportExportService и другие
├── MenuBar…       — лейбл и содержимое попапа строки меню
├── Views/        — главное окно, редактор встреч, настройки, About, countdown-панель Auto Join
└── KnockKnockBroApp.swift
```

Несколько решений, о которых стоит знать при чтении кода:

- **Правило повторения и исключения — разные сущности.** Расписание встречи описывает ПРАВИЛО («каждый день в 10:00»). Отклонения на конкретный день — Пропустить сегодня, отмена автоподключения на сегодня — хранятся отдельно, в `MeetingOccurrenceException`, поэтому пропуск одного дня никогда не трогает само правило.
- **Экземпляры встреч вычисляются, а не хранятся.** `OccurrenceEngine` разворачивает правило повторения в конкретные календарные даты по запросу, для заданного диапазона — это держит модель данных компактной и позволяет тестировать саму логику разворачивания независимо (включая переходы на летнее/зимнее время, границы месяцев и т.д.).
- **Уведомления планируются как дискретные одноразовые запросы**, а не один повторяющийся триггер — у `UNCalendarNotificationTrigger` с `repeats: true` нельзя отменить одно отдельное вхождение без отмены всей серии, а именно это нужно для «Пропустить сегодня».
- **Автоподключение работает в собственном плавающем `NSPanel`**, независимом от главного окна — countdown всегда виден, даже если главное окно закрыто.

## Планы (не входит в этот релиз)

- Настраиваемая громкость звука напоминаний
- Полностью независимая панель для промпта «встреча началась, пока вы спали» (сейчас — sheet на главном окне)
- Прямой запуск нативных приложений сервисов для тех, у кого есть задокументированная URL-схема (подтверждено для Zoom; для Microsoft Teams возможно, но исторически ненадёжно; приложение Яндекс Телемоста регистрирует схему `telemost://`, но точный формат URL пока не задокументирован публично)
